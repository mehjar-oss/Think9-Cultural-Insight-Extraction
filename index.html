01
Overview

Problem Statement

Think9’s Bharat Darshan ethnographic data is vast, complex, and deeply hierarchical. Extracting actionable cultural insights requires models that:

  • Understand nested narratives and layered cultural contexts
  • Summarize at multiple granularities while preserving nuance
  • Capture semantic shifts and regional variations
  • Handle long documents with diverse dialects and styles

Solution Objective

Build a flexible, scalable system to extract rich, multi-level cultural insights and summaries from large ethnographic corpora using a combination of architectures:

  • Recursive Language Models (RLM): Models hierarchical structure naturally; captures nested semantics.
  • Hierarchical Transformers: Efficient long-text modeling by segmenting and aggregating representations.
  • Graph Neural Networks (GNN): Models entities & their relations as graphs; excellent for relational reasoning.
  • Contrastive Learning + Topic Modeling: Learns semantic clusters without heavy supervision; tracks theme evolution.

02
Design

Core System Workflow

Dspy.ai will be embedded as the core platform for orchestrating data pipelines, training, deployment, monitoring, and collaboration.

  • Data Ingestion & Preprocessing: Clean and structure data (Python, SpaCy, Dspy.ai).
  • Semantic Parsing: Identify entities and themes (mBERT, PyTorch Geometric, BERTopic).
  • Multi-Level Summarization: Generate hierarchical summaries (BART, T5, Hugging Face).
  • Visualization Dashboard: Interactive UI for insights (React.js, D3.js, FastAPI).
  • Human-in-the-loop Feedback: Experts validate outputs (Label Studio, MLflow).

04
Summary

Multi-Level Strategy

  • Extractive summarization: Identify key sentences/phrases preserving important cultural details.
  • Abstractive summarization: Rewrite summaries maintaining semantic and cultural integrity.
  • Recursive summarization: Summaries at multiple granularities linked hierarchically.
  • Summaries enriched with metadata: Region, festival, time period tags for easy filtering.
